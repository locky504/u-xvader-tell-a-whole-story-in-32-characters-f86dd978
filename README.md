One Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story in the few words a passer-by sees in a phone's network list.

The entry:

```
DadChangedPasswordAfterDivorce
```

30 characters. A dad, a divorce, and a changed Wi-Fi password: the marriage is over, the household has split, and the petty revenge is already in motion — whoever is locked out knows exactly what happened, and so does every stranger who sees the name.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) prints the Wi-Fi name, validates it (1–32 characters, printable ASCII, no whitespace), and writes the identical text to `/output/entry.txt`, verifying the round-trip.
